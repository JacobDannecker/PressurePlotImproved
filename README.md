# Software begleitend zu einer Studienarbeit an der Hochschule Mannheim:
## Titel
Entwicklung eines parallelisierten Programms
zur Echtzeit–Auftriebsberechnung und
Druckvisualisierung an einem
Tragflügelmodell

## Kurzfassung
Ziel dieser Arbeit ist die Dokumentation der zweiten Version einer bestehenden An-
wendung. Die Anwendung dient zur Visualisierung von Drücken an der Oberfläche von
Tragflügelprofilen am Windkanal der Technischen Hochschule Mannheim. Es wird be-
schrieben, wie die neue Anwendung funktioniert und wie die neuen Funktionen, wie
beispielsweise die Berechnung des Auftriebs, integriert wurden. In der vorliegenden Arbeit
werden die Messgeräte, die Entwicklungswerkzeuge und die Funktion der Anwendung
vorgestellt. Ergänzt wird dies durch einzelne Codebeispiele. Zudem wird eine Bedie-
nungsanweisung bereitgestellt, die neben allen Funktionalitäten der Anwendung auch
deren Installation beschreibt. Das Ergebnis ist eine Dokumentation der überarbeiteten
Anwendung, die die Grundlage schafft, die Anwendung in Zukunft zu warten und neue
Funktionen zu implementieren.
## OS
Ubuntu getestet

## Features
- Visualisierung des Drucks auf der Oberfläche von Tragflügelprofilen
- Speichern der Messdaten
- Importieren von Profilen im Lednicer- oder Selig-Format
- Einfaches Setup
- Anzeigen der Anströmrichtung
- Bearbeiten und Speichern der Plots mit Matplotlib
- Demomodus zum Debugging ohne angeschlossene Messgeräte
- Konfiguration der Anwendung über eine Konfigurationsdatei
- Parallele Darstellung und Erfassung der Drücke
